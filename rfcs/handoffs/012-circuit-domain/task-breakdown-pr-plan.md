# Phase 4 — Task breakdown and pull-request plan

Entry point: [`README.md`](./README.md). One unit per change, in this order; a unit names the RFC rules it implements, the tests it adds, and the checks of the checklist that are run on it. **V** marks the four units a verifier session checks. Sizes are those of RFC-sized work (S small to XL very large); there are no durations because the serial team's throughput is not yet measured, and the architect reports one after the first milestone. The progress table at the end is updated with every review.
