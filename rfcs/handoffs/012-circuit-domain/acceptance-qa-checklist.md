# Phase 4 — Acceptance and QA checklist

Entry point: [`README.md`](./README.md). The checks the architect runs in review, the checks the verifier writes first for the four units marked **V**, and the owner's journey. Each row of section B begins with **the contract rules the unit touches**: the developer quotes them from their own RFC in the review request, and the verifier reads them there before writing a check. A check is a command or a procedure with a stated outcome; a check that cannot fail is not a check.

## A. The journey (external design revision 3; RFC 014 rule 12)

| # | Journey | Procedure | Passes when |

| J7 | Open the motor lab, run it, watch the speed settle and the controller's samples step along it, see the load step, change the set point, export the run with its trace and payloads, and replay it | In Chromium, Firefox and WebKit by `ci/browser/journeys.js`; then the owner by hand | The journey runs in three browsers; the browser's record replayed natively prints `matched` or `within-tolerance`; the same record exported without payloads prints `matched` while the chains agree and `needs-payloads`, with the interface saying why, when they do not; the owner confirms each control did what its label led them to expect (AC-016) |

## C. The release reviews (RFC 006 rule 5)

For 0.3.1 and for 0.4.0: acceptance and conformance tests under both Hosts; the security review (0.4.0 adds the capabilities of RFC 012 rule 3, the guest-sized list the Host lifts, and the pending-breakpoint and size limits to the threat model); documentation matches the released behaviour; dependency licences and advisories (`cargo deny`); the `CHANGELOG.md` entry; the RFC index; for 0.4.0 the release notes carry the evidence for each exit criterion and the cross-engine table; the owner approves the tag and publishes the crates.

## D. The owner's checks

The owner's pending hands-on checks of earlier releases and the usability test stay at the owner's pace and are not on the critical path. J7 and the pass over `motor-lab` at the end of M5 are the owner's for this phase.
