# ブラウザーインターフェース

リリース 0.2 のアプリケーション（RFC 005 第8節、外部設計 第3節）は、ひとつのウィンドウでひとつのシナリオをひとつずつ実行します。表示は英語と日本語です。Host はワーカーの中で動き、メインスレッドのシェルがビューモデルの内容を表示し、キャンバスに場面を描きます。

## 動かすには

```sh
cargo install --locked wasm-bindgen-cli --version 0.2.126   # 一度だけ。クレートが固定しているバージョン
ci/build-shell.sh
cd ci/browser && npm ci && node serve.js
```

そのうえで `http://127.0.0.1:8765/` を開きます。このサーバーは RFC 005 規則 33 の分離ヘッダーとポリシーを設定します。ヘッダーを設定できないホストでもアプリケーションは動きますが、そのときはステータス行に「テレメトリにメッセージを使います」と表示されます。一度開いたあとは、アプリケーションはオフラインでも起動し、「オフラインで利用できます」と表示します。

リリースごとに、ビルド済みのアプリケーションが `florn-app-<バージョン>.tar.gz` として配布されます。展開したものを、上記のヘッダーを付けて、バージョンごとに変わらないパス（たとえば `…/0.2.0/`）に置いてください。アプリケーションは利用者のもとで自分を更新することはなく、利用者が開くバージョンを選びます。配布物のすべてのファイルの SHA-256 はリリースノートにあります。

## 画面にあるもの

| 領域 | 内容 |
|---|---|
| ヘッダー | シナリオの名前。実行、一時停止、ステップとその単位、速度、リセット、時刻へ移動、アクター（すべて常駐、または容量を超えた分はスワップ）。言語。ステータス行：実行の状態、時点、介入の数、トランスポートの注記、落ちたレコード、律速要因（メモリとスワップを含む）、スワップの数、計測した描画時間、オフラインの状態、バージョンとオリジン |
| 学習ラボとファイル | 同梱されたシナリオ。OSPF のラボが先頭にあり、それぞれに見どころと試してみる介入の説明があります。シナリオを開く・保存する、モジュールをインポートする、プレビューのあとで実行記録ファイルをエクスポートする、実行記録ファイルを再実行する、チェックポイントを読み込む。開いた・保存した・取り込んだものはキャッシュとしてこのブラウザーに保持され、サイズとともに一覧され、それぞれ開き直したりエクスポートしたりできます |
| アクター | すべてのアクターを名前で。Tab で一度止まり、中は矢印キーで移動し、Enter で選択します。キャンバスの双子です |
| シナリオ | 作成：パレットからアクターを置き、ポートをつなぎ、属性とパラメータを設定し、変更を予定し、適用します。問題はそのフィールドに示され、Host の拒否も含まれます |
| トポロジー | アクターと接続。飛行中のメッセージ。ダウンしたリンクは破線、フォールトしたアクターは×印。ドラッグ、ホイール、キーで移動と拡大縮小。クリックで選択 |
| インスペクター | 選択中のアクター、接続、メッセージ、またはワールド。アクターの設定はフィールドとして。最新のテレメトリはモジュールのレイアウトでデコードされます。リンクとアクターの介入は、それぞれいつ適用されるかを示します。ワールドでは、保持しているチェックポイントを時点とメモリとともに示し、「いまチェックポイントを取る」「エクスポート」「ここから分岐」、そして分岐元を示します |
| タイムライン | トレースと Host のイベントから作られる実行の記録。アクターと種類で絞り込めます。送信を含む行はメッセージインスペクターを開きます。「ここまでステップ」は過去へも動きます |
| 介入 | 何をいつ求め、いつ適用されたか。戻ったことで取り消されたものは、その時刻に再適用するか破棄できます。終了した実行のものは、予定された変更として残せます |
| 状態 | すべての通知を、選んだ言語の文として、コードとともに |

再実行と再生は別のものです。アプリケーションは再実行します。つまり入力から実行をやり直し、記録された介入をその時点で適用します。このリリースではトレースの再生は行いません。

## 戻る、分岐する、チェックポイント

「時刻へ移動…」に現在より前の時点を入れるか、以前の行で「ここまでステップ」を押すと、実行は戻ります。Host は直近の保持しているチェックポイントを復元し、その時点まで先へ実行し直します。その時点より後に適用された介入があるときは、アプリケーションはまずそれを示して一覧します。戻るとそれらは取り消され、「介入」の下に時点とともに並び、それぞれその時刻に再適用（新しい要求として）するか破棄できます。終了した実行から戻ることも同じです。

ワールドのインスペクターは、Host が保持しているチェックポイントを、時点と使っているメモリとともに示します。「いまチェックポイントを取る」は次の時点の境界でひとつ追加し、「エクスポート」はプレビューのあとで `.florn-checkpoint` ファイルとして書き出し、「ファイル」の「チェックポイントを読み込む…」はそのファイルから実行を始めます。ファイルは同じシナリオとモジュールのものでなければならず、違えばフィールドの名前とともに拒否されます。「ここから分岐」は現在の実行を終え、ここまでの入力を引き継いだ新しい実行をこの時点から始めます。分岐のインスペクターは分岐元と時点を示し、タイムラインはそこに印を付け、親の記録は「ファイル」に保持されてエクスポートや再実行ができます。分岐はその時点から始まります。戻れるのはそこまでです。

## 容量を超えるアクター

ステータス行の容量は、このブラウザーが保持できる数です。それより多くのアクターを持つシナリオは、アクターが「すべて常駐」のときは必要数と容量とともに拒否されます。「容量を超えた分はスワップ」を選ぶと実行できます。Host は常駐する集合を保ち、各アクターを活性化の前に新しいインスタンスへ戻します。ステータス行は常駐数とアクター数とともに「スワップ中」と示し、スワップが実行を遅らせているときは「律速要因: スワップ」と示します。ダイジェストはどの Host でも常駐の実行と同じです。

## このブラウザーに保持されるファイル

開いた、保存した、取り込んだ、エクスポートしたものは、キャッシュとしてこのブラウザーに保持され、「ファイル」の下に種類、名前、サイズと合計とともに一覧されます。それぞれ一度のクリックで開き直すか、ファイルとしてエクスポートできます。ファイルが永続的な形です。ブラウザーはキャッシュを手放すことがあり、そのときアプリケーションはどの項目を失ったかを事実として伝えます。開いた・保存した・取り込んだ・エクスポートしたもの以外は保持されません。同梱のラボも保存されません。

## アプリケーションのインストール

ブラウザーが提供するところでは、アプリケーションをインストールできます。ウェブアプリケーションマニフェストとそのアイコンはアプリケーション自身のオリジンから来て、サービスワーカーはすでにオフラインで提供しているものと同じで、それ以外は何も加わりません。インストールは振る舞いを変えません。同じファイル、同じパスの同じバージョン、同じオフライン起動です。アドレスが内容を運ぶことはありません。URL が名指すのは同梱のラボとバージョンのパスまでで、シナリオ、実行記録、チェックポイントは、プレビューのあとでエクスポートしたファイルとしてだけ運ばれます。

## 言語

言語はヘッダーで切り替えます。再読み込みは不要で、入力途中の文字はそのまま残ります。日本語の文字は入力メソッドを通してフォームのフィールドに入力でき、キャンバスにもそのまま表示されます。表示される文はすべてカタログから取られた完全な文で、断片をつなぎ合わせることはありません。コードはどの言語でも同じです。

## 適合キットが確認すること

`ci/browser/journeys.js` は、受け入れ基準のジャーニー J1 から J5 と手順 P1 から P4 を Chromium、Firefox、WebKit で実行します（J5：ファイルから取り込んだモジュールが両方のハッシュとともに示され、置かれ、実行と再実行され、保持したファイルがバイト単位で同じにエクスポートされる。P1：破棄の通知と取り消された介入の一覧をともなって戻り、再適用する。P2：分岐元が示される分岐と、ネイティブで一致する両方の記録。P3：エクスポートしたチェックポイントを、開き直したアプリケーションで読み込み、ラボのダイジェストまで実行し、別のシナリオのものは拒否される。P4：容量を超えるシナリオが常駐では拒否され、スワップで実行されてランナーのダイジェストに至る）。さらに 0.2 の確認として、ラボが動き、経路がビューの中で収束する。ダウンさせたリンクがその時点とともに一覧され、実行が再び収束する。フレームがインスペクターでデコードされる。エクスポートした実行記録ファイルが再実行で一致する。保存したシナリオが読み込み直され、保存した実行を同じダイジェストで再実行する。空のシナリオから作った三角形が、ランナーが記録したダイジェストまで実行される。さらに、実行の途中で言語を切り替えて入力した文字が残ることを確かめ、すべてのランドマークにキーボードで一定の回数以内に到達し、アプリケーションをオフラインで起動し、描画時間を計測し、ネットワークログにオリジンがひとつしかないことを確認します。
