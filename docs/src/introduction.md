# florn

florn is a local-first platform for executable testbeds. Isolated WebAssembly actors run the logic under test; a deterministic Host simulates the world around them — a network, a circuit and its controller, a market.

**Emulate the component; simulate the world.**

This book is organised by reader.

| Reader | Start with |
|---|---|
| Maintainers and contributors | [Requirements specification](./requirements.md), the [external design](./external-design.md), then the RFCs in `rfcs/` |

Chapters for new users and for module authors are added with the releases that serve them.

## Status

florn is in Stage 0: foundational decisions, proofs of concept, and RFCs. No release exists yet. See `ROADMAP.md` in the repository.
